# 🚀 AstroGuard AI

### AI-Powered Asteroid Hazard Detection & Monitoring System

AstroGuard AI is a Machine Learning-based system designed to identify potentially hazardous Near-Earth Objects (NEOs) using astronomical and orbital parameters.

The project uses historical asteroid data to train a classification model that predicts whether an asteroid is potentially hazardous. AstroGuard AI combines machine learning with an interactive web interface to make asteroid-risk analysis easier to understand and demonstrate.

---

## 🌌 Project Overview

Asteroids and Near-Earth Objects are continuously monitored because some of them can potentially come close to Earth's orbit.

AstroGuard AI aims to provide an intelligent first-level screening system by analyzing asteroid characteristics and predicting whether an object belongs to the potentially hazardous category.
